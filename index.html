    1. АНВ-Гарант — Technical SEO & GEO Оптимизация (Яндекс Нейро & Алиса) Commercial · Real Estate
    Стек: Schema.org (LegalService), Яндекс Вебмастер, Яндекс Метрика, Топвизор, 301 Redirects, HTML5
    Проблема: Сайт агентства недвижимости (gk-anvgarant.ru) терял трафик из-за динамического JS-рендеринга критических текстов, дублей страниц и отсутствия микроразметки.
    Решение: Проведен технический аудит (10 пунктов ТЗ). Критический контент перенесен в первичный HTML без JS-зависимости. Внедрена Schema.org LegalService, настроена карта сайта, исключены дубли с www, спроектированы 5 посадочных страниц под Новороссийск/Геленджик с блоками прямого ответа под AI-выдачу Яндекса.
    Результат: 10 из 10 пунктов ТЗ подтверждены на живом домене через cURL и рендер-валидаторы. Единый профиль NAP согласован с Картами и 2ГИС.
    2. Анализатор оттока клиентов — Machine Learning & Product Analytics Fullstack & ML
    Стек: Python, CatBoost, Scikit-learn, FastAPI, React, Chart.js, Docker
    Проблема: Бизнес терял пользователей b2b-сервиса без понимания факторов риска и упущенной выгоды.
    Решение: Разработан аналитический сервис прогнозирования вероятности оттока на основе поведенческих метрик. Построен ML-пайплайн с feature engineering, реализован интерактивный веб-дашборд с калькулятором сохраняемой выручки (LTV) и экспортом отчетов в CSV/JSON.
    Результат: Качество классификации ROC-AUC 0.84, возможность сценарного моделирования удержания и приоритизации работы службы поддержки.
    3. Клуб собачников — Mobile Social & Service App Mobile · Offline-first
    Стек: Flutter, Dart, Firebase (Auth/Firestore), SQLite, Provider, Clean Architecture
    Проблема: Владельцы питомцев нуждались в удобном инструменте учета прививок, здоровья и карте площадок, работающем без связи.
    Решение: Спроектирована архитектура мобильного приложения по принципу Offline-first: локальное хранилище на SQLite с автоматической реактивной синхронизацией в облако при появлении сети. Интерактивная карта, фильтры и медицинский паспорт питомца.
    Результат: Полная автономность работы без сети, единая кодовая база для iOS и Android с чистой доменной логикой.
    4. Max ↔ Telegram Bridge — Message Routing & System Integration Backend · Integration
    Стек: Python, asyncio, aiohttp, Telegram Bot API, Docker, JSON-Schema
    Проблема: Необходимость надежной синхронизации служебных сообщений между внутренней системой и Telegram без потерь пакетов.
    Решение: Спроектирован асинхронный сервис-мост с гарантией доставки сообщений (at-least-once), буферизацией очередей, политикой повторных попыток (retries с exponential backoff), дедупликацией и валидацией контрактов через JSON-Schema.
    Результат: Нулевая потеря сообщений при временных сбоях сети, изоляция в Docker с мониторингом метрик задержки.
    5. Интернет-магазин «Прованс» — E-Commerce & Data Migration E-Commerce · Migration
    Стек: WordPress, WooCommerce, PHP, MySQL, 301 Redirects, SpaceWeb
    Проблема: Ограничения платформы Tilda не позволяли развивать каталог натуральной косметики, требовался перенос без потери позиций в поиске.
    Решение: Выполнен перенос 1888 товаров и 365 категорий на связку WordPress + WooCommerce. Спроектирована таблица из 90 точечных 301-редиректов для сохранения ссылочного веса, настроена кастомная витрина и фильтры каталога.
    Результат: 100% данных мигрировано без потерь, сохранен поисковый трафик, сайт стабильно работает на хостинге SpaceWeb.
